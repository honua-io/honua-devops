# Secrets Lifecycle

Baseline secrets lifecycle implementation for `honua-devops#8`.

## Bootstrap

The repo already bootstraps secret references and GitHub repo secret wiring through:

- `scripts/bootstrap-customer-repo.sh`
- `bootstrap/configure-honua-operator-ci.sh` generated by customer bootstrap
- `scripts/check-terraform-secrets.sh` for combined Terraform secret + repo-variable readiness

## Rotation

Use the rotation helper against a repo secret env file:

```bash
./scripts/rotate-operator-secrets.sh \
  --env-file ./rotation.env \
  --repo honua-io/honua-devops \
  --reason scheduled-rotation \
  --cadence 30d
```

The script writes `rotation-evidence.json` so the rotation event is auditable even in dry-run or manual approval flows.

Suggested baseline cadence:

- Honua and OTEL API keys: `30d`
- Terraform Git tokens: `90d`
- Break-glass tokens: rotate immediately after use

## Revocation

Use the revocation helper when a credential is suspected compromised or should be retired:

```bash
./scripts/revoke-operator-secrets.sh \
  --secret HONUA_DEVOPS_HONUA_API_KEY \
  --secret HONUA_DEVOPS_OTEL_API_KEY \
  --reason incident-revocation
```

The script writes `revocation-evidence.json` with the affected secret names and reason.

## Incident Loop

1. Revoke compromised secrets immediately.
2. Rotate replacement secrets into the repo or customer control repo.
3. Re-run preflight and the relevant smoke paths.
4. Attach rotation and revocation evidence to the incident record.

## Verification

```bash
./scripts/smoke-secret-lifecycle.sh
```
